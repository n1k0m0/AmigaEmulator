This Windows x64 update publishes the current development snapshot. The
seven-point compatibility roadmap remains in progress.

- Improve ECS/AGA display handling, including SuperHires sampling, interlace
  field weaving, native presentation and mode-exit cleanup. Add guest display
  diagnostics and regression coverage.
- Extend 68020/68030 cache and MMU fault-retry behavior with additional
  instruction and partial-transfer tests. Full cycle timing and restartable
  faults are still unfinished.
- Correct blitter modulo decoding and selected game/presentation defects.
  Add guarded real-game continuations, including Cannon Fodder's first
  single-drive mission and later Celtic Heart platform and enemy sections.
  These checks do not establish full game compatibility or completed levels.
- Expand AmigaOS 3.1.4 display, application and controller checks on the
  supported machine profiles, plus GameRunner input, image and restore guards.

Download `AmigaEmulator-0.1.2-win-x64-setup.exe` for Windows x64. The setup
includes the .NET runtime; its SHA-256 checksum is supplied alongside it.

**No Kickstart ROMs, AmigaOS/Workbench, games, installed disk images or
personal saves are included.** Provide your own ROM and media.

Known limits: later Cannon Fodder missions and disk requests, the reported
Siedler border state, later Celtic Heart stages, full SuperHires/interlace
and programmable display modes, exact 020/030 timing and fully restartable
MMU faults require more work. Optional 68881/68882, a distinct A4000/040
and Zorro III are not implemented as complete hardware. The shared
C64/Amiga relay has not been deployed on the existing proxy.

See the [roadmap](https://github.com/n1k0m0/AmigaEmulator/blob/v0.1.2/AmigaEmulator/Docs/MachineModels.md)
and [gameplay guide](https://github.com/n1k0m0/AmigaEmulator/blob/v0.1.2/Tools/GameRunner/README.md)
for the tested states and remaining work.
