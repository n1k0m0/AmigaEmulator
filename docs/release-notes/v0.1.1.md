First Windows x64 installer release. This is an actively developed emulator;
A500 is the primary target and the additional machine profiles are previews.

- Correct PAL short/long field timing and presentation (312/313 scanlines).
  This removes the reproduced Cannon Fodder early-confirmation address error.
- Profile-driven floppy controller optimization, retaining drive priority,
  legacy restore and identical CPU/frame results in paired measurements.
- 68030 ATC history replacement, exact replacement-state restore and migration
  of older MMU/cache states. Machine savestates now use core format 17;
  older saves remain supported, while older emulator builds cannot read new saves.
- Matching-ROM AmigaOS 3.1.4 application, IDE/SCSI, persistence and reset/restore
  checks for A1200 and A3000, extending the previously tested older boards/A4000.
- Re-reviewed Siedler frame/menu/construction references and 339 regression tests.

Download `AmigaEmulator-0.1.1-win-x64-setup.exe` and install it on Windows x64.
The setup includes the .NET runtime. Its SHA-256 checksum is supplied alongside
the installer. Future updates are offered through the emulator's GitHub updater.

**No Kickstart ROMs, AmigaOS/Workbench, games or installed disk images are
included.** Provide your own ROM when prompted on first startup. Cancelling
without a usable ROM exits cleanly. Configure the model and matching ROM/RAM
through `F10` → `SETTINGS`.

Known limits remain: a separate Cannon Fodder cold DF0-only Disk-2 handoff still
produces black output, later missions/islands and the full game/model matrix
need further gameplay review, and native superhires/full interlace weaving,
programmable display timing and full restartable MMU faults are unfinished.
68881/68882, A4000/040 and Zorro III are not implemented or offered as complete
hardware. The shared C64/Amiga relay is available in source; deployment on the
existing proxy is a separate step.

See the [roadmap](https://github.com/n1k0m0/AmigaEmulator/blob/v0.1.1/AmigaEmulator/Docs/MachineModels.md)
and [gameplay guide](https://github.com/n1k0m0/AmigaEmulator/blob/v0.1.1/Tools/GameRunner/README.md)
for evidence, required media configurations and remaining acceptance work.
