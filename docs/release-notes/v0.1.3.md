This Windows x64 development update records verified emulator and gameplay
progress. The seven-point compatibility roadmap and A1000 work remain open.

- Add an opt-in single 8, 16 or 32 MiB Zorro III RAM board for A3000/A4000
  development testing. Native guest Autoconfig, reset, 32-bit RAM access and
  savestate handling pass unit tests and Kickstart boot checks. Installed
  AmigaOS memory detection and multiple cards remain unverified.
- Extend GameRunner with bounded RAM watches, write traces, snapshots and
  stricter checkpoint assertions for reproducible game diagnostics.
- Add independently repeated full DF0 cold-start input routes for Celtic
  Heart on A3000/Kickstart 3.1. Stages 1–9 reach visible next-stage titles;
  Stage 10 remains active, with living gameplay verified through X3008.
- Preserve the previously verified Cannon Fodder first mission and other
  gameplay checks. Later campaign progression and single-drive disk requests
  still require work.

Download `AmigaEmulator-0.1.3-win-x64-setup.exe` for Windows x64. Setup
includes the .NET runtime; a SHA-256 checksum is supplied alongside it.

**No Kickstart ROMs, AmigaOS/Workbench, games, installed disk images or
personal saves are included.** Provide your own ROM and media.

Known limits: later Celtic Heart stages, the reported Siedler border state,
full SuperHires/interlace and programmable display modes, exact 020/030
timing, fully restartable MMU faults, an optional 68881/68882 FPU, a distinct
A4000/040, and A1000 bootstrap/WCS are unfinished. Zorro III is currently
an opt-in single-board development feature, not a complete expansion system.
The shared C64/Amiga relay has not been deployed on the existing proxy.

See the [roadmap](https://github.com/n1k0m0/AmigaEmulator/blob/v0.1.3/AmigaEmulator/Docs/MachineModels.md)
and [gameplay guide](https://github.com/n1k0m0/AmigaEmulator/blob/v0.1.3/Tools/GameRunner/README.md)
for tested states and remaining work.
